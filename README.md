# 📸 DarkCam

A camera app for sharper, better photos, with a built-in editor.

## ✨ Features
- 🌙 Photo modes: Standard, NR, DRO, HDR, EXPO
- 🔭 Telephoto view with 5×–20× zoom
- 🎨 Filters and custom effects
- 🤖 AI enhance and 2×/4× upscale
- ☀️ Glare and haze reduction
- ↔️ Before/after compare slider
- 📐 Auto-level and straighten
- 🖼️ Background blur / remove (beta)
- ⏱️ Timer, burst and repeat shots
- 📍 Location and timestamp stamps

## 📥 Download
Get the latest APK from the [Releases](../../releases) page.

## 📲 Install
1. Download the APK on your phone.
2. Open it and allow "install from this source" if asked.
3. Install and open DarkCam.

## 🔑 API keys (optional)
AI enhance and upscale use your own keys (Picsart, RapidAPI, Gemini, etc.).
Add them in **Settings**. Your keys stay on your device.
